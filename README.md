# blog-platform-with-comments
A full-stack Blog Platform with Comments developed as part of my Thirnex internship. The project allows users to register, log in, create and manage blog posts, and interact through comments. It focuses on user authentication, RESTful APIs, database integration, and interactive web development.
Blog Platform with Comments

Project Overview

The Blog Platform with Comments is a web application developed as part of my internship task at Thirnex. It provides a platform where users can create, publish, edit, and delete blog posts and share their thoughts through comments.

The project aims to demonstrate full-stack web development skills, user authentication, RESTful API development, and database integration.

Features

- User registration and login
- User authentication
- Create, view, edit, and delete blog posts
- Add comments to blog posts
- Interactive and user-friendly interface
- Backend API integration
- Database integration for storing users, posts, and comments

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: MongoDB
- API: RESTful APIs
- Version Control: Git and GitHub
